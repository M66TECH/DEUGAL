deugal

Le gestionnaire de snippets qui vit dans ton terminal. Tes commandes restent chez toi, dans un seul fichier JSON, et tu les retrouves en une seconde.

local-first zero cloud sans dependance lourde TypeScript

Installation

npm install -g @m66tech/deugal
deugal --version

En trente secondes

$ deugal add "purge docker" "docker system prune -af" -t docker -l bash
Added 4f8a1c92  purge docker

$ deugal find dkrpg
4f8a1c92  purge docker    docker     bash   0

$ deugal use 4f8a --copy
docker system prune -af
Copie dans le presse-papier.

Ce qu il sait faire

CommandeEffet
deugal addAjouter un snippet (argument, stdin pipe ou editeur)
deugal browseNavigateur interactif: filtrer, previsualiser, copier, editer
deugal search / findRecherche ponderee, floue sur titres et tags, ou en regex
deugal useSortir le contenu brut, pipe-friendly, compteur d usage
deugal relatedSnippets qui partagent des tags
deugal tag / tagsGerer et renommer les tags, voir les compteurs
deugal export / importJSON, YAML ou CSV, filtrable par tag, langue ou periode
deugal sync / historyVersionner et sauvegarder le store dans git
deugal dedupe / similarDoublons exacts ou quasi identiques
deugal doctor / recover / migrateDiagnostic, restauration de sauvegarde, migration de format
deugal completionsScripts bash, zsh et powershell

Ou vivent tes donnees

~/.deugal/snippets.json   tes snippets
~/.deugal/config.json     tes preferences
~/.deugal/*.bak1..bak3    sauvegardes automatiques

Change de dossier avec DEUGAL_HOME. Ecriture atomique, sauvegardes rotatives et commande recover en cas de pépin.

Pourquoi

Chaque developpeur garde un fichier de commandes ou 40 onglets ouverts. Deugal remplace ca par une commande, sans compte, sans synchronisation obligatoire et sans laisser tes commandes sur un serveur.
